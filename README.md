# AI Study Assistant

An interactive AI-powered web application built with Streamlit and the Google GenAI SDK that helps students summarize study materials, create practice quizzes, and break down complex topics.

## Features
- *PDF & Text Support:* Upload study guides or paste notes directly.
- *Summarization:* Condense dense chapters into key takeaways.
- *Quiz Generator:* Test your knowledge with custom-generated multiple-choice questions.
- *Tutor Mode:* Receive clear, simplified explanations for difficult concepts.
